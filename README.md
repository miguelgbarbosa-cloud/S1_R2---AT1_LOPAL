Este conjunto de exercícios apresenta os conceitos fundamentais da programação através de fluxogramas estruturados:

Tarefa: foi uma especie de revisao realizada pelo professor para reelembrar os alunos.

1. Saudação Personalizada: Foca na interação básica, onde o sistema lê o nome do usuário e exibe uma mensagem de boas-vindas personalizada.

2. Soma de Dois Números: Demonstra a manipulação de variáveis e operações aritméticas simples, recebendo dois valores e exibindo o resultado da soma entre eles.

3. Verificação de Maioridade: Introduz a estrutura condicional, onde o sistema avalia se a idade informada é maior ou igual a 18 para exibir "Maior de idade" ou, caso contrário, "Menor de idade".

4. Classificação de Números: Utiliza decisões encadeadas para identificar se um número lido é positivo, negativo ou zero, cobrindo todas as possibilidades lógicas.

5. Cálculo de Média Estudantil: Consolida o aprendizado ao realizar um processamento aritmético onde duas notas são coletadas, somadas e divididas por dois para gerar e exibir a média final.
